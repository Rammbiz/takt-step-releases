# Такт · Степ: установники

Готові установники «Такт · Степ» для Windows. Коду програми тут нема.

Встановлена програма, починаючи з версії 1.4.0, сама бере звідси нові версії: під час запуску тихо перевіряє й
завантажує, а ставить лише після кнопки «Перезапустити й оновити». Перевірити вручну: «Довідка › Перевірити оновлення».

Поставити вперше: відкрити останню версію в розділі «Releases» праворуч і завантажити `TaktStep-<версія>-setup.exe`.
Програма ставиться для всіх користувачів комп'ютера, тож Windows попросить дозволу.
